# GenAI Lab

生成AIに関する技術・サービス・開発手法を実際に試すための実験リポジトリ。

特定のフレームワークやサービスに依存せず、生成AIを実際の開発・データ分析・業務にどう活用できるかを検証する。

## Purpose

- 生成AI関連技術を実際に触って理解する
- Gemini / Vertex AI などのGoogle Cloud系サービスを試す
- Hugging Faceを通じたオープンソースLLM/SLMやモデル評価・データセットの活用を検証する
- RAG、Agent、Tool Use、MCPなどの技術を検証する
- データ分析と生成AIを組み合わせる
- AIを使った開発そのものを実験する
- 実験結果や知見をGitに蓄積する

## Philosophy

> Learn by building.

完成されたアプリケーションを作ることだけを目的とせず、
小さな実験を繰り返し、生成AIの技術や可能性を理解する。

## Notes

生成AIの技術は変化が速いため、特定のライブラリや実装方法に
過度に依存せず、原理・構成・ユースケースを理解することを重視する。
